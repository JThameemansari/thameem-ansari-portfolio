# Thameem Ansari — Portfolio

A responsive, dependency-free portfolio site for GitHub Pages. The site supports light and dark themes, uses rem-based sizing for accessible scaling, includes a keyboard- and touch-friendly skills carousel, and serves the résumé PDF directly from the repository.

## Publish this portfolio with GitHub Pages

### 1. Create a GitHub repository

Sign in to GitHub and create a new **public** repository, for example `thameem-ansari-portfolio`. A descriptive repository name gives you a shareable address such as `https://YOUR-USERNAME.github.io/thameem-ansari-portfolio/`.

If you prefer the shorter address `https://YOUR-USERNAME.github.io/`, name the repository exactly `YOUR-USERNAME.github.io`. GitHub requires that special repository name to match your username.

### 2. Add the portfolio files

From the new repository, choose **Add file → Upload files**. Upload these files from this folder to the repository's top level:

- `index.html`
- `styles.css`
- `script.js`
- `favicon.svg`
- `Resume_Thameem.pdf`
- the `icons/` folder, which contains the skill logos used in the toolkit carousel

Choose **Commit changes** to add them to the repository's default branch. Keep the files together in the top-level folder so the résumé link and other assets work.

### 3. Turn on GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the default branch (usually `main`) and the `/ (root)` folder, then choose **Save**.
4. Wait for the Pages deployment to finish. The published URL will appear in **Settings → Pages**.

Open that URL to check the live site, then share it with recruiters. Changes pushed or uploaded to the selected branch and folder will publish automatically.

The site uses Google Fonts when online and falls back to system sans-serif fonts if those fonts are unavailable.
